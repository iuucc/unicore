### 踩过的坑（都要记住）
1. `isinstance(x, np.ndarray.dtype)` 在 NumPy 2.x 抛 `TypeError`（那是描述符不是类型）。
2. `apply_overrides` 用浅拷贝会就地污染嵌套配置 → 多实验共用 base 时静默串味。
3. 陈旧 `.pyc` 会让"无残留命名"的验收 grep 失败（含 3.13 编译的旧字节码）→ 清理 `__pycache__`。
4. 自己在文档注释里写出 grep 命令原文，会破坏该 grep 自己的门禁。
5. **长训练重定向输出必须加 `-u`**：`print()` 被块缓冲，中途看不到 `epoch=… val_loss=…`，
   一度让我误判 T0.5 已崩溃。tqdm 走 stderr 不受影响。
6. 池只读性的强制执行：写守卫 `assert_readonly_pool` 语义是"禁止写入池内"，不能用它来"允许读"。
   正确做法是 `is_in_pool()` 正面断言 + 探测前后比对文件数/总字节/最大 mtime 指纹。

## T0.7 执行要点与新增环境坑（追加）

### 环境坑（Windows 平台，会反复咬人）
7. **Git Bash 的 `ps -W` 第 4 列才是 Windows PID**（列序：PID PPID PGID **WINPID** TTY UID STIME COMMAND）。
   用第 1 列去 `taskkill` 会报"没有找到进程"。
8. `taskkill /F /T /PID <winpid>` 在 Git Bash 里必须加 `MSYS_NO_PATHCONV=1`，
   否则 `/F` 被路径转换吃掉，报"无效参数/选项 - '//F'"。
9. 通过 Bash 调用 `powershell.exe` 会被安全策略拦截（"bypasses security checks"）；
   需要 PS 时用专用工具，或改用 Bash + psutil 取进程信息。PS 工具也偶发"exit code 0 但无输出"。

### 修掉的实现缺陷
- `bench_hardware.py` GPU 段：`torch.Generator()` 默认在 CPU，配 `device="cuda"` 的张量会抛
  `Expected a 'cuda' device type for generator but found 'cpu'` → 15 个组合全废。
  改用 `torch.Generator(device=device)`；不要用"CPU 生成再搬运"，那会把 H2D 拷贝计入单步耗时。
- `scripts/first_experiment.py` 顶层 `import sklearn` 会让 Windows spawn 出的每个 DataLoader worker
  重新导入 `scipy.stats → scipy.interpolate`，其 docstring 处理偶发抛 `SystemError`
  （`scipy/_lib/_docscrape.py:477`），worker 启动即崩溃并被反复重建。
  → 把 pandas/sklearn 下沉到 `evaluate()` / `write_report()` 内部。崩溃数 1 → 0。

### DataLoader 实测（C=34, bs=128, 每组合 2000 样本，单次干净运行）
| num_workers | 稳态 samples/s | 剩余物理内存 |
|---:|---:|---:|
| 0 | 222.4 | 16.98 GiB |
| 4 | 1148.1 | 16.99 GiB |
| 8 | 3069.1 | 16.98 GiB |
| 12 | 3062.9 | 17.03 GiB |
- 与手册 §0.3.7 短测（0→310.3、4→2399.1、8→2274.9、12→4412.0）相比：`=0` 更低（222 vs 310，
  短测只有 384 样本偏乐观），`=12` 更低（3063 vs 4412，手册 NOTES 自己也标注了"明显偏乐观"）。
  **结论方向不变且更强：0 → 8 提升约 13.8×。**
- **未复现"每 worker 常驻约 1.4 GB"**：C=34 下剩余内存几乎不动（16.98 → 17.03 GiB）。
  原因是 `SyntheticEEGDataset` 用 mmap 读 npy，共享页不计入独占内存。
  双卡 worker 上限仍按手册保持 ≤16（保守无害）。
- 追加结论：DataLoader 段落必须同时测 **C=1**——手册 §0.3.7 的口径是 C=34，但当前主线是单通道，
  而数据集单样本成本随通道数变化，不能互相代言。T0.7 的"墙钟下降"验收依赖 C=1 的数字。
